🍔 Canteen Order Management System

A Python-based Canteen Order Management System for managing food orders, calculating bills, applying discounts, and processing orders through a web interface.

🚀 Features

- 🛒 Menu-based food ordering
- 💰 Automatic bill calculation
- 🏷️ Discount calculation
- ✅ Order validation
- 🧾 Billing and order processing
- 🌐 FastAPI backend
- 💻 HTML, CSS and JavaScript frontend
- 📋 Order processing logs

▶️ How to Run

1. Clone the repository

git clone https://github.com/shimoligupta/Canteen-order-management.git

2. Open the project

cd Canteen-order-management

3. Create a virtual environment

python -m venv venv

4. Activate the virtual environment

For Windows PowerShell:

venv\Scripts\Activate.ps1

5. Install dependencies

pip install fastapi uvicorn

6. Start the server

uvicorn backend.main:app --reload
